Hey, I'm Mahdi 👋

I'm a CS grad and systems engineer who got hooked on the question of *what makes a system actually trustworthy* — not "trust me" trustworthy, but provably, architecturally trustworthy. That curiosity has pulled me through secure backend design, API security, and the messy realities of regulated financial platforms, and these days it's pulling me deep into privacy-enhancing tech and applied cryptography.

I think the most interesting problems live in the gap between "technically encrypted" and "actually private." That's the gap I like working in.

### 🔐 The stuff I care about

- Designing systems where security isn't a feature you bolt on — it's the load-bearing wall
- API security, authentication, and secure communication protocols
- Applied cryptography and access control that survives contact with real users
- Privacy-preserving, resilient design — systems that hold up when things go wrong

### 🛠 How I work

Backend & API design, secure protocols, and a strong bias toward Linux and infrastructure I can reason about end to end. I'd rather understand one layer deeply than wave at ten.
